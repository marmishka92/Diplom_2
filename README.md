Дипломный проект. Задание 2. Автоматизированное тестирование API

Тесты на регистрацию пользователя:
1. Проверка успешного создания нового уникального пользователя.
2. Попытка зарегистрировать пользователя, который уже существует в системе.
3. Попытка создать пользователя без заполнения одного из обязательных полей.

Тесты на авторизацию:
4. Успешный вход под ранее созданным пользователем.
5. Попытка авторизации с некорректным логином или паролем.

Тесты на создание заказа:
6. Создание заказа с авторизацией пользователя.
7. Создание заказа без авторизации.
8. Создание заказа с корректным списком ингредиентов.
9. Попытка создания заказа без указания ингредиентов.
10. Создание заказа с ошибочным (некорректным) хэшем ингредиентов.
